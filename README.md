# AcessaWeb - Frontend SPA com Foco em Acessibilidade

O **AcessaWeb** é uma aplicação web de página única (SPA) desenvolvida com React e Vite, focada em proporcionar uma experiência acessível e inclusiva para todos os utilizadores.

## 🚀 Tecnologias Utilizadas
- React
- Vite
- JavaScript (ES6+)
- HTML5 Semântico
- CSS3 / Acessibilidade (WCAG 2.1 & WAI-ARIA)

## ♿ Requisitos de Acessibilidade
- Conformidade com as diretrizes WCAG 2.1.
- Uso de atributos WAI-ARIA e navegação total por teclado.
- Alto contraste e leitores de ecrã suportados.
